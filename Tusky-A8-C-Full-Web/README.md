# Tusky Phoenix — A8-C complete website

Extract this ZIP with its directory structure intact. With Python 3 installed, run `python preview.py` and open http://127.0.0.1:8769/ . For a different port, use `python preview.py --port 8870`. The server is bound to localhost; Ctrl+C stops it. Preview over HTTP, not by double-clicking index.html, because the page uses native modules.

The package contains current C1–C4 HTML/CSS/JS, all local runtime and approved source images, three variable fonts, the OFL license, this portable server and SHA-256 inventory. No project-folder access or application dependency installation is required. C1/C2 are unchanged; C3 adds a short carrier-field reveal; C4 combines approved ribbon concept media with semantic historical sample information. Both chapters have complete static no-JS/reduced-motion layouts.

The newly supplied source image is preserved byte-for-byte. Its phone UI is AI concept media, not verified current production UI. The webpage's fixed CSS matte covers the baked-in status/authenticity/verification area at every viewport. Do not treat the unmodified source PNG or its text as product evidence. HTML historical sample values are a separate record, visibly distinguished from the image; information reading is not authenticity proof.

This is a local prototype awaiting Product Owner review. No current query service or authenticity result is asserted; no deployment, commit or push was performed. The separate A8-C Delta Review ZIP contains only this phase's source changes, new media, QA and recorded motion.
